Automation (Docker):

Wszystko startuje z katalogu głównego repo (tam gdzie jest docker-compose.yml):

  docker compose up -d --build

To automatycznie:
  1) postgres  - tworzy schemat (create.sql), ładuje dane przykładowe (input.sql)
     i naprawia sekwencje (sequences.sql) przez /docker-entrypoint-initdb.d
  2) data_loader - wczytuje dane USOS z backend/app/services/*.json do bazy
     (pomija jeśli już załadowane - idempotentne)
  3) fast_api  - startuje API na http://localhost:8000/docs (Swagger UI)

Reset do stanu wyjściowego (schema + seed + USOS od nowa):

  docker compose down -v
  docker compose up -d --build

Ręczne zapytania do bazy:

  docker exec -it ksi_opinion_base psql -U ksi_opinion_base -d ksi_opinion_base

(Wcześniejsze ręczne kroki z psql < create.sql itd. nie są już potrzebne.)
